# Roadmap

The roadmap describes intended direction, not committed dates. Each capability must remain optional, local-first, explicitly negotiated, and backward compatible with PalCenter's official REST API fallback.

## v0.1 — Project foundation

- Repository, governance, and contribution standards
- Versioned API and architecture contracts
- Event, stream, and coordinate-space design
- UE4SS extension lifecycle
- Embedded health, version, and capability discovery
- Configuration, logging, and lifecycle validation

## v0.2 — Compatibility and packaging

- API authentication before any authoritative gameplay or player endpoint
- Published Palworld and UE4SS compatibility matrix
- Reproducible extension package
- Administrator installation and upgrade validation

## v0.3 — Player sessions

- Authoritative player joined events
- Authoritative player left events

## v0.4 — Player lifecycle

- Authoritative death events
- Authoritative respawn events

## v0.5 — World context

- Coordinate-space identity
- Dungeon detection
- World Tree context

## v0.6 — Communities and construction

- Guild information
- Base information

## v0.7 — Operations

- Server performance metrics

## v0.8 — Administration

- Moderation API
- Auditable moderation actions

## v1.0 — Stable Companion API

- Stable, documented API compatibility policy
- Supported installation and upgrade path
- Production security and operational guidance

Possible later capabilities include authoritative structure, breeding, boss, and capture events. They will be designed through the normal proposal process rather than treated as committed milestone scope.
