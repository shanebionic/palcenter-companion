## Installation and lifecycle

- [ ] Build `main.dll` with the authorized pinned toolchain.
- [ ] Validate the staged ZIP and record its SHA-256.
- [ ] Install the complete `PalCenterCompanion` folder.
- [ ] Confirm UE4SS discovers it.
- [ ] Confirm `start_mod` executes.
- [ ] Confirm `on_unreal_init` executes once; a duplicate callback is ignored and logged.
- [ ] Confirm initialization returns without blocking the game thread.
- [ ] Confirm PalServer reaches its normal playable state.
- [ ] Confirm PalDefender still loads and operates normally.
- [ ] Confirm Offline Raid Protection still loads and operates normally.
- [ ] Shut down PalServer normally and capture `Companion stopped`.
- [ ] Confirm port 8213 is released after shutdown.
- [ ] Restart and confirm exactly one listener starts.
- [ ] Complete at least three start/stop cycles without a crash or leaked port.

## Endpoint checks

Run all three from the PalServer host, then run health from the network location used by PalCenter:

```powershell
Invoke-RestMethod http://127.0.0.1:8213/palcenter/v1/health
Invoke-RestMethod http://127.0.0.1:8213/palcenter/v1/version
Invoke-RestMethod http://127.0.0.1:8213/palcenter/v1/capabilities
Invoke-RestMethod http://<private-palserver-address>:8213/palcenter/v1/health
```

- [ ] Responses match the documented v1 contract.
- [ ] Health contains no credentials, player data, or gameplay information.
- [ ] The PalCenter-network request succeeds only through the intended private path.

## Log evidence template

Startup should include:

```text
[PalCenterCompanion] PalCenter Companion v0.1.0
[PalCenterCompanion] Companion initialized
[PalCenterCompanion] Listening on 127.0.0.1:8213
[PalCenterCompanion] API Version v1
```

Normal shutdown should include:

```text
[PalCenterCompanion] Companion stopped
```
